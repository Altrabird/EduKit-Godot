# Makmal Sains Ajaib 3D

**Main sekarang / Play now: https://altrabird.github.io/Makmal-Sains-Ajaib-3D/**

Cikgu Nurul's after-school science lab, in 3D and in the browser. Walk around the lab
(drag to look, scroll to zoom) and click a bench to start one of five KSSR Sains / RBT
missions. Each mission earns 1–3 stars, and the stars float above its bench.

| Bench | Mission | KSSR link |
|---|---|---|
| Saturn | **Sistem Suria (3D):** click each planet, then click its orbit around the Sun, from Mercury to Neptune. Correct planets start orbiting. | Sains Tahun 4–6, Bumi & Sistem Suria |
| Books | **Kitaran Hidup:** drag stage cards into order for the frog, butterfly and plant life cycles. | Sains Tahun 2–3 |
| Magnet | **Magnet:** drag the magnet onto objects to test them (the steel ones jump), then sort everything into "ditarik / tidak ditarik". | Sains Tahun 3, Magnet |
| Robot kit | **Litar Ringkas:** build three circuits (bulb, motor, LED + resistor) and switch them on. A pencil or plastic ruler is an insulator and breaks the circuit. | Sains Tahun 4–6, Elektrik · RBT |
| Plant | **Keperluan Tumbuhan:** a fair test. Predict which pot grows best (water + light / no water / no light), watch a 7-day time-lapse, then answer what plants need. | Sains Tahun 1–2 |

Bahasa Melayu and English (BM / EN button). Cikgu Nurul speaks the instructions in a
Malaysian Malay voice.

## Source

Built with Godot 4.7 (Compatibility renderer, WebGL 2) on the EduKit asset kit:
https://github.com/Altrabird/EduKit-Godot (game source in `games/makmal/`).
This repository holds the web build only.
